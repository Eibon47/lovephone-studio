# 隐私与本地数据说明

LovePhone Studio 以本地使用为主。它不提供账号系统、云端同步或统一的服务端数据库。

## 本地保存的数据

以下数据默认保存在当前浏览器的 IndexedDB 中：

- 小手机配置、主题、图标、小组件和上传图片
- 角色资料、聊天记录、记忆、日记、纪念日与晚安记录
- 自动与手动备份

浏览器清理站点数据、使用无痕窗口或更换设备，都可能让这些数据不可恢复。请在“完成”页定期导出 JSON 或主题包。

## API Key 与模型请求

在 Windows 上，API Key 由本机 AI 桥接服务使用当前 Windows 用户的 DPAPI 加密保存，不写进浏览器配置、导出 JSON 或主题包。

当你发送聊天、生成日记总结、自动写入记忆或生成问候时，应用会把完成该操作所需的角色设定、相关记忆、近期聊天内容和你的请求发送给你在设置中自行选择的模型服务商。请先阅读该服务商自己的隐私与数据使用政策。

## 音乐功能

音乐功能会在本机调用网易云 CLI 与 MPV。网易云登录状态由 CLI 自己保存，不进入 LovePhone 配置。歌曲、歌词、封面和账号数据受网易云音乐服务条款约束。

## 删除数据

你可以在应用内删除单个角色、聊天、记忆、日记和纪念日；也可以在浏览器站点设置中清除 `127.0.0.1` 的站点数据，以删除本机保存的全部内容。清除前请确认已导出需要保留的配置。

## 不收集的内容

本项目不内置统计、广告、远程字体、第三方追踪脚本或云端账号系统。自定义主题和小组件也不允许引用外部网络资源。

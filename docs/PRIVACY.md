# 隐私与本地数据说明

LovePhone Studio 以本地使用为主。它不提供账号系统、云端同步或统一的服务端数据库。

## 本地保存的数据

以下数据默认保存在当前浏览器的 IndexedDB 中：

- 小手机配置、主题、图标、小组件和上传图片
- 角色资料、聊天记录、记忆、日记、纪念日与晚安记录
- 自动与手动备份

浏览器清理站点数据、使用无痕窗口或更换设备，都可能让这些数据不可恢复。请在“完成”页定期导出 JSON 或主题包。

## API Key 与模型请求

在 Windows 上，API Key 由本机 AI 桥接服务使用当前 Windows 用户的 DPAPI 加密保存，不写进浏览器配置、导出 JSON 或主题包。

部署到 Netlify 的网页版本不使用 Windows DPAPI。用户填写的 API Key 只保存在当前浏览器会话中，并随 AI 请求通过本站的 Netlify Function 转发到用户选择的模型服务商；密钥不会写入配置、导出 JSON、IndexedDB、GitHub 或 Netlify 环境变量。关闭浏览器后，用户需要重新填写 Key。

当你发送聊天、生成日记总结、自动写入记忆或生成问候时，应用会把完成该操作所需的角色设定、相关记忆、近期聊天内容和你的请求发送给你在设置中自行选择的模型服务商。请先阅读该服务商自己的隐私与数据使用政策。

## 音乐功能

本地音乐文件保存在当前浏览器的 IndexedDB 中，不会上传到 LovePhone 的服务器。在线音乐仅在你主动填写兼容 API 地址后启用；搜索词、歌曲 ID、歌词请求和扫码登录凭证会发送给你填写的服务。扫码登录凭证保存在当前浏览器，请只使用自己部署或明确可信的服务。歌曲、歌词、封面和账号数据受相应音乐服务条款约束。

## 自定义 App

自定义 App 安装包会在独立沙箱页面中运行，不能直接访问 LovePhone 的父页面、API Key、音乐登录 Cookie 或其他 App 的独立数据。它只能通过 `LovePhone` API 访问你在安装或权限管理页明确授权的能力。

- 授予 `character.read`、`chat.read`、`memory.read` 或 `diary.read` 后，App 代码可以读取对应的本地内容。
- 授予 `network` 后，App 可以向安装页展示并确认过的 HTTPS 域名发送请求；这些请求可能携带 App 自己组织的数据。
- 授予 `ai.chat` 后，App 可以使用你已连接的 AI 服务生成内容。这不会把 API Key 交给 App，但会消耗你的模型额度，并把该次请求内容发送给你选择的模型服务商。
- 你可以在“设置 → 自定义 App 管理”随时收回权限、禁用或卸载 App。卸载会删除该 App 的独立数据。

请只安装来源可信的 App 包，并在安装前查看其请求的权限和联网域名。LovePhone 不会替第三方 App 审核其业务逻辑或数据处理方式。

## 删除数据

你可以在应用内删除单个角色、聊天、记忆、日记和纪念日；也可以在浏览器站点设置中清除 `127.0.0.1` 的站点数据，以删除本机保存的全部内容。清除前请确认已导出需要保留的配置。

## 不收集的内容

本项目不内置统计、广告、远程字体、第三方追踪脚本或云端账号系统。自定义主题和小组件也不允许引用外部网络资源；自定义 App 只有在用户明确授权 `network` 和指定域名后才能联网。

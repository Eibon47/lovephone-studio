# LovePhone 安全自定义系统设计

## 目标

在现有“整机美化”和“App 美化”两页中，为开发者提供统一的“+ 自定义”入口和侧边编辑面板。支持整机设计变量、手机壳、配色、图标套装、桌面布局、现有 App 主题、作用域 CSS、声明式小组件以及离线 ZIP 导入导出。

## 产品结构

- 继续保留两页美化流程，不增加第三个长页面。
- 每组预设的最后一项为“+ 自定义”。
- 点击后打开左侧面板内的编辑抽屉，右侧手机实时预览。
- 普通模式显示可视化字段；开发者模式额外显示 CSS、清单、数据源、动作和包管理。
- 取消编辑恢复打开抽屉前的配置；应用后才写入正式配置。

## 安全边界

- 自定义包只允许 JSON、CSS、PNG、JPG、WebP、GIF、WOFF 和 WOFF2。
- 禁止 JavaScript、HTML、可执行文件、外部 URL、`@import` 和远程字体。
- CSS 自动限定到整台手机、指定 App 或指定小组件。
- 小组件只能调用白名单数据源和动作，不能读取 API Key 或任意聊天、记忆内容。
- 导入前校验包版本、文件类型、文件数量、总大小、资源哈希和 CSS。
- 导入失败不改变当前主题；应用失败回退到最后一个有效配置。

## 数据模型

`theme.customization` 保存当前生效的轻量配置：

- `developerMode`
- `tokens`
- `phoneShell`
- `desktop`
- `iconPack`
- `appThemes`
- `widgets`
- `activePackageIds`

独立 IndexedDB 素材库保存导入包、图片、字体和 CSS 原文。配置中只保存素材 ID 或经过限制的小型内联预览。

## 自定义包

ZIP 包包含 `manifest.json`、可选的 `theme.css`、`preview.png` 和 `assets/`。支持导出当前项目或完整主题；导入后可“只保存”或“保存并应用”。所有素材必须在 ZIP 内，不允许引用外部网络资源。

## 第一版不包含

- 任意 JavaScript 或 HTML
- 第三方代码直接运行
- 完全自定义业务逻辑 App
- 远程主题市场
- 远程图片、字体、CSS 或接口

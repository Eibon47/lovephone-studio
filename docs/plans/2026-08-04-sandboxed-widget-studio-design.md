# 安全沙箱小组件工作室设计

## 目标

把现有的简单数据组件升级为三层编辑体验：模板库、可视化样式、开发者代码。旧组件继续可用，所有组件仍由 GridStack 负责拖动和保存布局。

## 模板

首批提供时钟、天气、日历、音乐播放器、相框、角色状态、纪念日、快捷启动、心情记录和便签十种模板。模板创建的是可继续编辑的组件实例，而不是不可修改的固定成品。

## 数据模型

每个组件保存模板 ID、显示模式、数据来源、动作、尺寸、样式、可选图片和代码配置。代码配置包含 HTML、CSS、JavaScript，以及显式授权的数据来源和动作。规范化层限制字段、数量、字符串长度和本地图片格式，旧数据缺少新字段时自动补齐。

## 沙箱

代码组件在 `iframe sandbox="allow-scripts"` 中运行，不包含 `allow-same-origin`。`srcdoc` 使用 CSP 禁止网络连接、外部资源、表单、父页面导航和插件。父页面只向组件传入获准的天气、时间、音乐、角色等结构化数据。组件只能通过 `postMessage` 请求白名单动作，父页面再次校验组件 ID、消息来源、动作名称和目标 App。

代码不能读取父页面 DOM、localStorage、IndexedDB、Cookie、API Key 或聊天记录。静态检查会额外拒绝网络、存储、父窗口访问和导航相关 API，并限制 HTML、CSS、JavaScript 大小。

## 编辑体验

自定义小组件抽屉包含“模板、样式、代码”三个页签。模板页负责新增和选择实例；样式页编辑名称、数据、动作、图片、尺寸和颜色；代码页提供 HTML/CSS/JavaScript 编辑框、权限选择、安全检查结果和实时手机预览。关闭或取消会恢复打开抽屉前的配置，应用后再持久化。

## 验证

测试覆盖旧配置迁移、十种模板、代码安全校验、沙箱属性、CSP、数据最小化、动作白名单和 HTML 转义。界面验证覆盖创建模板、切换页签、编辑代码、运行组件、拖动布局及刷新恢复。

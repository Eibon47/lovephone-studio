# LovePhone 真实 AI 接入方案

## 目标

让搭建者在左侧选择允许使用的模型服务商，让最终用户在小手机“设置”中选择服务商，只填写 API Key 和模型名称即可测试并使用真实 AI 聊天。

## 配置分层

- 可导出配置：服务商选择、当前服务商、模型名称、桥接地址、自定义服务商地址。
- 仅本机内存：API Key。它不进入浏览器存储，也不进入导出的 JSON。
- 角色覆盖：角色默认跟随全局服务商，也可以单独选择已启用的服务商。

## 请求链路

1. 浏览器把 API Key 提交给本机 AI 桥接服务。
2. 桥接服务仅在当前进程内保存密钥。
3. 聊天 App 组装角色设定、关系、说话风格和记忆摘要。
4. 桥接服务按 OpenAI、Anthropic 或 Gemini 协议发送请求并转发流式文本。
5. 页面实时显示回复，并把对话正文保存在小手机配置中。

## 支持范围

- OpenAI 兼容协议：OpenAI、xAI、DeepSeek、火山引擎方舟 / 豆包、通义千问、Kimi、智谱、MiniMax、腾讯混元、百度千帆、硅基流动、OpenRouter、Ollama 和自定义服务商。
- Anthropic Messages 协议。
- Google Gemini `streamGenerateContent` 协议。

## 上线边界

当前桥接服务适合本机 DIY 使用。若发布为公网多用户产品，应把内存密钥改为按账号隔离的加密密钥存储，并补充鉴权、限流、用量统计、审计与内容安全策略。

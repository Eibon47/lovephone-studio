# 聊天 App 高自由度美化设计

## 范围

聊天 App 作为第一套完整样板，提供整体、角色列表、聊天气泡和输入栏四组结构化编辑项。现有预设主题继续作为基础设计语言，结构化配置在预设之上覆盖，开发者限定 CSS 保持最高优先级。

## 配置层级

聊天专属配置保存到 `theme.customization.appThemes.chat.chat`。配置包含页面与顶部栏颜色、内容边距、角色列表行高和头像、双方气泡、消息头像与时间、快捷回复、会话工具栏以及输入栏。规范化层负责默认值、颜色校验、数值范围和枚举白名单，旧配置自动得到完整默认值。

## 编辑体验

聊天自定义主题增加“整体、角色列表、聊天气泡、输入栏”四个页签。顶部提供“列表预览”和“对话预览”，切换时右侧手机保持在聊天 App，不返回桌面。所有范围、颜色、选择器和开关实时映射到右侧。

## 布局边界

核心功能采用受约束布局，不开放任意绝对坐标。用户可以控制对齐、显示隐藏、内容边距、尺寸、间距、圆角、最大宽度和输入栏浮动形态。这样能保持不同手机尺寸下可用，并避免发送按钮或消息内容被移出屏幕。需要像素级控制时继续使用当前 App 的限定 CSS。

## 验证

测试覆盖默认值补齐、范围限制、运行时变量、显示状态类和旧主题兼容。界面验证覆盖列表与对话切换、双方气泡差异、头像和时间开关、输入栏样式以及保存后刷新恢复。

# LovePhone Studio 两分钟产品演示

## 录制方法

1. 在项目根目录执行 `npm run demo`。
2. 浏览器打开 `http://127.0.0.1:5180/demo/`。
3. 使用 1920×1080、30 FPS 录屏，浏览器缩放保持 100%。
4. 全屏后点击“开始演示”，按照右侧口播提示讲解。

快捷键：空格暂停/继续，左右方向键切换章节，`H` 隐藏口播栏，`R` 返回开场，`F` 进入浏览器全屏。

## 口播稿

欢迎来到 LovePhone Studio，小手机工坊。它可以帮助你用简单的选择和配置，制作一台属于自己的 AI 陪伴小手机。

首先，你可以像搭积木一样选择需要的功能。聊天、角色和设置是基础能力，音乐、记忆、日记和纪念日等功能可以自由添加。

接着，创建自己的陪伴角色。填写名字、称呼、性格和说话方式，再连接你自己的 AI 服务，就可以开始聊天。不同角色也可以使用各自独立的设定和模型。

LovePhone 不只有聊天。音乐 App 可以搜索和播放歌曲，播放状态还会同步到桌面的唱片组件，让小手机更像一台真正属于你的设备。

在美化页面中，可以更换手机壳、颜色、图标和桌面组件。所有修改都会实时显示在右侧，不需要写代码，也能慢慢搭出自己喜欢的样子。

制作完成后，可以保存在当前浏览器、导出 JSON 备份，也可以下载成本地 HTML。

这就是 LovePhone Studio。选择功能，创建角色，再把它变成只属于你的小手机。
